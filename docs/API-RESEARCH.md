# Official API research — 2026-11-06

Retrieved official sources before implementation; source inspection is not live inference.

* [TypeSafe System One](https://docs.typesafe.ai/api/system-one.md) embeds OpenAPI 0.2.0: POST /v1/systemone, bearer auth, state string/object/array, named map questions, noul/choice/score. Choice 1–255, score 1–10. Nullable/omitted structured instructions permitted, native predicate criteria true/false supported, no documented refusal variant. No documented fixed question cap. Official docs index and public org repositories advertise Python and JS SDKs; no Go SDK discovered in this search.
* [OpenAI create](https://developers.openai.com/api/reference/resources/decisions/methods/create) and [guide](https://developers.openai.com/api/docs/guides/decisions): POST /v1/decisions, currently gpt-6-luna. Ordered 1–400 questions, typed 2–255 choices, 2–10 score levels, optional wire names, explicit refusal. Native input_json object/object-array with limits; nullable cache/safety controls and shared text/image explicit cache marker. Official Go SDK already implements Decisions and presence metadata; our value is native cross-protocol semantics, not inventing a missing official Go API.
* [H2O model](https://huggingface.co/h2oai/h2o-lightning-4b), [actual main shim source](https://huggingface.co/h2oai/h2o-lightning-4b/raw/main/h2o_lightning_shim.py): native /v1/systemone and distinct /v1/decisions handler, extended probability_source/effort_used/attention_mode metadata. Main is mutable, reviewed only on this date, not a pinned deployed-server guarantee. H2O preset uses native System One and conservative default 10 score levels; override only against a separately verified deployment. No quantization, attention calibration, speed, memory or model-quality claims.
