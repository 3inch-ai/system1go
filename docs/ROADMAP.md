# Roadmap

Initial 0.1: explicit common API, native System One/OpenAI Decisions, three typed kinds, bounded/cancelable HTTP, semantic regression tests and honest researched docs.

Next, based on consumer demand: permitted hosted/native deployment smoke tests with pinned model/server identities; additional verified compatible servers; clearer compile-time helpers for dynamic JSON/choice unions; API drift fixtures and fuzzing. Candidate rich media/Box, explicit splitting/partial execution and opt-in retry/fallback need a separate design because they alter semantics, spending or scope. No promised release dates or unverified provider support.

1.0 requires stable semantic/result/error contracts and real consumer feedback. No gateway, model management, GPU operations or model-quality platform is planned without demonstrated need.
